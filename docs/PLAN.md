# بصيرة (Basira OS) — خطة التطوير الكاملة

النسخة الحية من الخطة (بتنعدّل): https://claude.ai/artifact/L2R9boWoX5oYNsBBmVxKrJ

## الرؤية والنطاق

بصيرة نظام واقع مختلط بيشتغل كامل على موبايل أندرويد جوّا صندوق VR: بتشوف غرفتك من الكاميرا، ونوافذ التطبيقات طايرة فيها، وبتتحكم بإيدك وبصوتك بالعربي. الهدف إنه يطلع أول إصدار alpha عام على GitHub خلال 5 شهور تقريباً، والشغل جزئي.

الشي اللي بيميزنا: المساعد العربي اللي **بيفهم الشاشة** (بيقرأ الصفحة ويلخصها ويعبّي فيها)، وكمان **ذاكرة الغرفة** و**وعي الحرارة**.

**داخل النسخة الأولى (v1):**
- Passthrough مقسوم stereo لعينين، مع تشويه للعدسات بيتظبط بشاشة معايرة
- نوافذ ويب ثابتة بالغرفة (6DoF مع ARCore، و3DoF على الأجهزة اللي ما بتدعمه)
- مؤشر بالنظر (نقطة بنص الشاشة) والقرصة بتكون النقرة، وكمان سحب وتمرير وتحريك نوافذ
- مدير نوافذ وشريط سفلي (Dock) وشاشة تطبيقات
- مساعد صوتي عربي بيفتح ويسكّر ويرتّب ويبحث، وبيلخّص الصفحة المفتوحة
- مساحات محفوظة للغرف، ووضع تبريد تلقائي

**برا v1:**
- تشغيل تطبيقات أندرويد الأصلية جوّا النظام. هاد بيحتاج صلاحيات نظام، والحل الواقعي هو نسخ الويب للتطبيقات
- التحكم المباشر بالإصبع بالفضاء (hand ray)، لأن v1 بيعتمد على النظر والقرصة
- موديلات إيد وكلمة تنبيه مدرّبة من عنا، وتعدد المستخدمين، والألعاب

### 0 · تجهيز وتجارب
- [ ] تتأكد إن الموبايل موجود بقائمة ARCore، وإن «Google Play Services for AR» مثبّت
- [ ] تقيس صندوق الـ VR: المسافة بين العدستين، وإذا وجهه مفتوح للكاميرا
- [ ] repo `basira-os` بالـ modules الفاضية، ومعها Hilt وversion catalog وCI
- [ ] تشغيل عينة ARCore الرسمية (hello_ar_kotlin) على جهازك وقياس الحرارة بعد 10 دقايق
- [ ] تشغيل عينة MediaPipe Hand Landmarker وقياس الـ fps

### 1 · Passthrough لعينين
- [ ] نرسم الـ camera texture تبع ARCore (OES) على الشاشة كلها
- [ ] نقسم الشاشة لعينين مع إزاحة IPD
- [ ] shader للتشويه (barrel) بمعاملات k1 وk2
- [ ] شاشة معايرة للـ IPD والتشويه، والقيم بتنحفظ بـ DataStore
- [ ] عداد fps وحرارة ظاهر بوضع المطوّر

### 2 · نافذة ثابتة بالغرفة
- [ ] مصفوفات view وprojection لكل عين من الـ pose تبع ARCore
- [ ] مستطيل عليه WebView من VirtualDisplay وSurfaceTexture
- [ ] Anchor قدّامك على بعد متر ونص
- [ ] وضع 3DoF بحساس Rotation Vector للأجهزة بدون ARCore

### 3 · النظر والقرصة
- [ ] Raycast من نص النظر للنوافذ، مع مؤشر وhover
- [ ] MediaPipe على نفس صورة الكاميرا بدقة منخفضة
- [ ] State machine للقرصة (مفتوح، قريب، مقروص، سحب) مع فلتر One Euro
- [ ] تحويل النقطة (u, v) لـ MotionEvent: نقر، تمرير، سحب
- [ ] مقبض تحت النافذة للتحريك، وزاوية لتغيير الحجم

### 4 · مدير النوافذ والواجهات
- [ ] WindowManager: فتح، سكّر، ترتيب، وحد أقصى للنوافذ الحيّة
- [ ] الـ Dock والشاشة الرئيسية وشريط الحالة بالـ Compose زي البروتوتايب
- [ ] كتالوج تطبيقات الويب (الاسم، الرابط، الأيقونة، User-Agent)
- [ ] وضع «استدعاء» بيجيب كل النوافذ قدّامك

### 5 · المساعد الصوتي
- [ ] زر تكلّم بالـ Dock أولاً، وبعدين كلمة تنبيه «يا بصيرة»
- [ ] STT عربي وLLM مع أدوات: `open_app` `close_window` `place_window` `search` `recall`
- [ ] أوامر أساسية بتشتغل أوفلاين بمطابقة كلمات
- [ ] TTS وشريط المساعد بحالاته (بيسمع، بيفكّر، بينفّذ)

### 6 · فهم الشاشة

## المخاطر والحلول

| الخطر | الحل |
| --- | --- |
| الموبايل بيسخن وبيخنق الأداء | مستويات جودة مربوطة بـ Thermal API، ونقيس بكل مرحلة |
| القرصة بتنفهم غلط من زاوية الكاميرا | عتبتين مع تأكيد على 3 فريمات، والنظر بيحدد الهدف والإيد بس بتأكد |
| الـ anchors ما بتضل بين جلسة وجلسة | v1: نقطة أصل بنظرة. v2: Cloud Anchors |
| مواقع بتمنع نسخة الويب أو بتحوّل للتطبيق | User-Agent لسطح المكتب لما يلزم، وبنوضّح القيد |
| التعرّف على اللهجات ضعيف | STT من ورا interface بنجرّب عليه أكتر من مزوّد، والـ LLM بيصحّح النية |
| النت مش مستقر | الأوامر الأساسية أوفلاين، والـ LLM بس للأشياء المعقدة |
| النطاق بيكبر | لكل مرحلة بوابة، وأي ميزة جديدة بتروح لقائمة v2 |
