# بصيرة (Basira OS) — خطة التطوير الكاملة

النسخة الحية من الخطة (بتنعدّل): https://claude.ai/artifact/L2R9boWoX5oYNsBBmVxKrJ

## الرؤية والنطاق

بصيرة نظام واقع مختلط بيشتغل كامل على موبايل أندرويد جوّا صندوق VR: بتشوف غرفتك من الكاميرا، ونوافذ التطبيقات طايرة فيها، وبتتحكم بإيدك وبصوتك بالعربي. الهدف إنه يطلع أول إصدار alpha عام على GitHub خلال 5 شهور تقريباً، والشغل جزئي.

الشي اللي بيميزنا: المساعد العربي اللي **بيفهم الشاشة** (بيقرأ الصفحة ويلخصها ويعبّي فيها)، وكمان **ذاكرة الغرفة** و**وعي الحرارة**.

### المشاريع المشابهة وكيف منتفوّق

أقرب مشروع إلنا [Orion Vision OS](https://github.com/MultiX0/orion-vision-os) (alpha، مجرّب على S22 Ultra بس، وصاحبه نفسه بيقول «it gets hot»، والكود مش منشور). منتفوّق عليه بهالأشياء:

| المحور | كيف |
| --- | --- |
| الحرارة | الحرارة شغلة من المرحلة 1 مش من الآخر. أرقام fps وحرارة منشورة بكل مرحلة، و30 دقيقة بدون خنق كبوابة |
| فهم الشاشة | تلخيص وأسئلة على الصفحة وتعبئة فورمات، مش بس افتح وسكّر |
| عربي وأوفلاين | كلمة تنبيه «يا بصيرة» على الجهاز بـ v1، والأوامر الأساسية بدون نت |
| واقعية | تثبيت النوافذ على الحيط والطاولة، وإضاءة النوافذ حسب الغرفة، وصوت مكاني |
| سهولة الإعداد | معايرة الصندوق بمسح QR تبع Cardboard، وتقرير جهاز من شاشة التشخيص |
| مفتوح | كود مفتوح من أول يوم، مع CI وتستات وتوثيق لكل مرحلة |

**داخل النسخة الأولى (v1):**
- Passthrough مقسوم stereo لعينين، مع تشويه للعدسات بيتظبط بشاشة معايرة
- نوافذ ويب ثابتة بالغرفة (6DoF مع ARCore، و3DoF على الأجهزة اللي ما بتدعمه)
- مؤشر بالنظر (نقطة بنص الشاشة) والقرصة بتكون النقرة، وكمان سحب وتمرير وتحريك نوافذ
- مدير نوافذ وشريط سفلي (Dock) وشاشة تطبيقات
- مساعد صوتي عربي بيفتح ويسكّر ويرتّب ويبحث، وبيلخّص الصفحة المفتوحة
- كلمة تنبيه «يا بصيرة» بتشتغل على الجهاز (موديل KWS صغير)، والشامي أولاً
- مساحات محفوظة للغرف، ووضع تبريد تلقائي
- تثبيت النوافذ على الأسطح (planes من ARCore)، وإضاءة النوافذ حسب الغرفة
- معايرة الصندوق بمسح QR تبع Cardboard، والمعايرة اليدوية كبديل
- تسجيل فيديو من جوّا النظام (خرج GL لعين وحدة) للـ README واللينكدإن

**برا v1 (قائمة v2):**
- تشغيل تطبيقات أندرويد الأصلية جوّا النظام. هاد بيحتاج صلاحيات نظام، والحل الواقعي هو نسخ الويب للتطبيقات
- التحكم المباشر بالإصبع (hand ray): بيتجرّب كمرحلة 3.5 ورا feature flag بعد بوابة المرحلة 3، وما بيصير الأساس بـ v1
- الإيد بتغطي النوافذ (Depth API occlusion): بنجرّبها بالمرحلة 8 إذا الحرارة سمحت
- STT وLLM صغير على الجهاز (لاستخراج النية بس، وبحالة NORMAL بس)، وموديلات إيد مدرّبة من عنا
- قراءة النص الحقيقي بالغرفة (OCR عربي)، لأن ML Kit ما بيدعم العربي
- تعدد المستخدمين والألعاب

### 0 · تجهيز وتجارب
- [x] تتأكد إن الموبايل موجود بقائمة ARCore، وإن «Google Play Services for AR» مثبّت
- [x] تقيس صندوق الـ VR: المسافة بين العدستين، وإذا وجهه مفتوح للكاميرا
- [x] repo `basira-os` بالـ modules الفاضية، ومعها Hilt وversion catalog وCI
- [x] شاشة تشخيص: ARCore، موديل الجهاز، الحرارة، معدل تحديث الشاشة، ونسخ تقرير الجهاز

- [x] تشغيل عينة MediaPipe Hand Landmarker وقياس الـ fps

### 1 · Passthrough لعينين
- [x] نرسم الـ camera texture تبع ARCore (OES) بحجمها الزاوي الصحيح (مش ممطوطة على الشاشة كلها)

- [x] shader للتشويه (barrel) بمعاملات k1 وk2
- [x] شاشة معايرة للـ IPD والتشويه وحجم العرض، والقيم بتنحفظ بـ DataStore، مع profiles جاهزة (مسح QR تأجّل)
- [x] عداد fps وحرارة ظاهر بوضع المطوّر
- [x] ThermalGovernor أولي: بيقرأ الحالة وبيطلع QualityLevel، وبيتسجّل بالـ overlay

### 2 · نافذة ثابتة بالغرفة

## المخاطر والحلول

| الخطر | الحل |
| --- | --- |
| الموبايل بيسخن وبيخنق الأداء | مستويات جودة مربوطة بـ Thermal API، ونقيس بكل مرحلة |
| القرصة بتنفهم غلط من زاوية الكاميرا | عتبتين مع تأكيد على 3 فريمات، والنظر بيحدد الهدف والإيد بس بتأكد |
| الـ anchors ما بتضل بين جلسة وجلسة | v1: نقطة أصل بنظرة. v2: Cloud Anchors |
| مواقع بتمنع نسخة الويب أو بتحوّل للتطبيق | User-Agent لسطح المكتب لما يلزم، وبنوضّح القيد |
| التعرّف على اللهجات ضعيف | STT من ورا interface بنجرّب عليه أكتر من مزوّد، والـ LLM بيصحّح النية |
| النت مش مستقر | الأوامر الأساسية أوفلاين، والـ LLM بس للأشياء المعقدة |
| النطاق بيكبر | لكل مرحلة بوابة، وأي ميزة جديدة بتروح لقائمة v2 |
